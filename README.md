# drizzle-base

Reactive Drizzle on Postgres: write plain drizzle-orm (schema in columns, drizzle-kit migrations, Drizzle
Studio), get Convex-style reactive queries, a shared cache, ACID mutations and a typed client.

Layout and module rules: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

A community project for the Drizzle ecosystem — **not affiliated with the Drizzle Team**. Licensed under
[Apache-2.0](LICENSE).

Status: in development (DZB-01a). Start with [`docs/specs/DZB-01-foundation.md`](docs/specs/DZB-01-foundation.md).
`spikes/` holds the throwaway probes the design rests on; each has a `FINDINGS.md`.
